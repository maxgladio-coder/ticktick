# 真机验收清单

这些场景需要在 Android 手机或模拟器上实际运行。JVM 测试不能代替音频链路和系统后台行为验证。

- 30 / 120 / 137 / 300 BPM 播放，听取连续性；核对 1 / 3 / 4 / 6 / 12 拍循环和 2 / 3 / 4 等分。
- 播放中修改速度、拍号和细分，确认无重复启动、连串补拍或崩溃。
- 快速开始／停止、旋转屏幕、系统返回后重开，确认仅一个声音流，设置保留。
- 锁屏或切换应用持续播放；通知停止按钮可停止声音，随后通知消失。
- 拒绝通知权限仍可播放，应用内可停止；前台服务由系统的活动应用入口管理。
- 通话、其他应用抢占音频焦点、耳机拔出时停止；不自行恢复。
- 通过手机扬声器、有线耳机、Bluetooth 分别检查声音和亮拍的实际延迟。
- 静音、系统媒体音量为零、关闭系统触感时行为合理。
- 敲击 8–12 次，故意加入抖动、漏一拍或误触，观察结果；连续换速后能跟随。
- 停顿 4 秒后下一次敲击重开窗口；重置立即清空；应用只在点击后更改 BPM。
- 小屏、横屏和系统字体放大时可滚动到所有设置，底部开始／停止仍可操作。
- TalkBack 可读取调速、拍号、设置和 TAP 按钮，并能完成一次操作。
