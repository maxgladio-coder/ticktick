共 26 个本机测试通过，无失败或跳过。敲击测试包括多个目标 BPM 下的时间戳抖动、意外重复输入、漏拍、持续变速、历史范围和 10,000 次随机输入；超过两分钟、280 个连续间隔的滚动窗口测试确认不停止输出且旧速度被最近窗口替代。新增 240/280 BPM、各 400 次连续抖动敲击测试，确认热身后窗口保留 40 次敲击（39 个间隔），该组输入误差不超过 1.5 BPM。音频时钟测试渲染两分钟、137 BPM、三等分的 PCM，逐个主拍核对期限误差不超过约一个采样帧。

UI 测试验证 98.4 的内部估算只显示为 98，点击应用后使用同一个整数；同时覆盖 ±5 操作、设置入口、小屏可滚动性、底部按钮可达性，以及快捷 TAP 在按下时记录一次、抬起不重复记录。

更新测试使用注入的响应，覆盖数字版本比较、相同版本和降级、非法版本/预发布、无 APK、异常下载地址、404、限流、服务器及网络错误。UI 测试覆盖手动检查、检查中禁用重复操作、更新说明、点击下载才打开地址、失败重试及已是最新状态；并验证设置中可滚动到更新按钮。版本直接读取已安装包的 PackageInfo，不另存版本常量。

GitHub 在线发布状态和真实 Android 浏览器下载/覆盖安装需要另行验证，以上模拟响应测试不代表设备端联网验证。
